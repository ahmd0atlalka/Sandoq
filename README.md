# صندوق الشيخ عبدالله نمر درويش للمنح - نظام تسجيل الطلاب

## 📋 وصف المشروع

نظام إلكتروني متكامل لإدارة تسجيل الطلاب وتأكيد الحضور واستلام الشيكات في احتفال صندوق الشيخ عبدالله نمر درويش للمنح.

## ✨ الميزات الرئيسية

### 🔍 للمتطوعين
- **البحث عن الطلاب** بالمجموعة أو رقم الهوية
- **تأكيد الحضور** للطلاب
- **تأكيد استلام الشيكات** (بعد تأكيد الحضور)
- **واجهة سهلة الاستخدام** باللغة العربية

### 📊 للمديرين
- **لوحة إدارة شاملة** مع إحصائيات فورية
- **رسوم بيانية تفاعلية** لتوزيع الطلاب
- **جدول شامل** لجميع الطلاب
- **تصدير البيانات** إلى Excel
- **طباعة التقارير** بتنسيق احترافي

## 🚀 التقنيات المستخدمة

- **React.js** - واجهة المستخدم
- **Firebase Realtime Database** - قاعدة البيانات
- **Tailwind CSS** - التصميم والأنماط
- **Chart.js** - الرسوم البيانية
- **Lucide React** - الأيقونات

## 🔐 نظام الأمان

### كلمات المرور
- **`Admin`** - للمتطوعين (البحث والتحديث)
- **`A12345`** - للمديرين (لوحة الإدارة الكاملة)

## 📦 التثبيت والتشغيل

### المتطلبات
- Node.js (الإصدار 14 أو أحدث)
- npm أو yarn

### خطوات التثبيت

1. **استنساخ المشروع**
```bash
git clone https://github.com/your-username/sandoq-student-registration.git
cd sandoq-student-registration
```

2. **تثبيت التبعيات**
```bash
npm install
```

3. **تشغيل المشروع**
```bash
npm start
```

4. **بناء المشروع للإنتاج**
```bash
npm run build
```

## 🗄️ هيكل قاعدة البيانات

### نموذج بيانات الطالب
```json
{
  "Code": "A-1",
  "id": 215932286,
  "fullname": "يزن محمد احمد عماريه",
  "nameAsgroup": "يزن محمد احمد عماريه",
  "city": "ابطن",
  "phone": "+972508392185",
  "email": "example@email.com",
  "IS_Participated": 1,
  "Is_received": 1
}
```

### الحقول المهمة
- **`Code`** - رقم المجموعة (مثل A-1)
- **`id`** - رقم الهوية
- **`fullname`** - الاسم الكامل
- **`nameAsgroup`** - الاسم حسب المغلف
- **`city`** - المدينة/البلد
- **`IS_Participated`** - حالة الحضور (0 = حاضر، 1 = غير حاضر)
- **`Is_received`** - حالة استلام الشيك (0 = مستلم، 1 = غير مستلم)

## 🎯 كيفية الاستخدام

4. **تصدير البيانات** أو طباعة التقارير

```javascript

  apiKey: "your-api-key",
  authDomain: "your-project.firebaseapp.com",
  databaseURL: "https://your-project-default-rtdb.firebaseio.com",
  projectId: "your-project-id",
  storageBucket: "your-project.appspot.com",
  messagingSenderId: "your-sender-id",
  appId: "your-app-id",
  measurementId: "your-measurement-id"
};
```

```json
{
  "rules": {

    ".write": true
  }

```
